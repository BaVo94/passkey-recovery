Anmeldungsbestätigung

Fehlermeldung

Wenn Sie sich auf einem Gerät anmelden möchten, auf dem noch kein Passkey hinterlegt ist, wird Ihnen dort ein Code angezeigt. Geben Sie diesen Code hier ein, um die Anmeldung freizugeben.

Geben Sie niemals einen Code ein, der Ihnen von einer anderen Person genannt wurde. Ein solcher Code gibt dieser Person Zugriff auf Ihr Konto.
