Anmeldung auf einem neuen Gerät

Auf diesem Gerät ist noch kein Passkey hinterlegt. Sie können sich dennoch anmelden, indem Sie die Anmeldung auf einem Gerät bestätigen, auf dem Sie bereits angemeldet sind.

Geben Sie dazu Ihren Kontonamen ein. Anschließend erhalten Sie einen kurzen Code, den Sie auf dem bereits angemeldeten Gerät eingeben.
